# About this folder

This `.beads/` folder is the working tracker that {{OWNER}}'s coding agents use while working in this
repository. It is written and read by the `br` command and is committed so that the work graph travels
with the repository.

- It is not the team's list of open work. That list stays where the team keeps it.
- Nobody on the team needs to read it or act on it.
- `issues.jsonl` is machine-written; pull requests collapse it. Please leave it out of reviews.
- When the engagement ends, the folder can stay as history or be removed at the team's request.
